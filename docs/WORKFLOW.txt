WORKFLOW — Primary entrypoints (see scripts/README.md)

1. Full prod-image gate (unit + full integration + Playwright, prod-built images)
   ./scripts/test-prod-gate.sh
   Uses: config/.env.prod, deploy/docker-compose.full.yml

2. Quick prod-like smoke (build + unit + stack + short tests, then down)
   ./scripts/test-prod-like-smoke.sh
   or: ./ci-local.sh smoke prod

3. CI (compose-driven stages: build, unit, smoke, integration, e2e, all)
   ./ci-local.sh [all|build|unit|smoke|integration|e2e] [dev|prod]
   Uses: config/.env.*, deploy/docker-compose.yml

4. Dev + breakpoints (Surreal/Redis in Docker; backend on host)
   ./scripts/dev-debug.sh  then  just backend-watch
   Uses: config/.env.dev
   Prod snapshot: SURREAL_SEED_DIR + SURREAL_SEED_FORCE=1 — see docs/DAILY_WORKFLOW.md

5. Backend (terminal 1 — all in Docker)
   ./scripts/start-back.sh              # start (build if needed)
   ./scripts/start-back.sh --no-build    # start existing images only, no rebuild
   ./scripts/stop-back.sh                # stop stack
   Uses: config/.env.dev (or .env.prod), deploy/docker-compose.yml

6. Frontend (terminal 2 — standalone Yew or Tauri)
   ./scripts/start-front.sh       # browser: Yew/Trunk at FRONTEND_PORT
   ./scripts/start-tauri.sh       # desktop app: Tauri window (embeds same Yew)
   Uses: config/.env.dev (BACKEND_URL, FRONTEND_PORT). Tauri needs: cargo install tauri-cli

7. Production (install images CI built — same tags as GHCR)
   ./scripts/install-from-ci.sh <tag>   (from repo; wraps deploy/deploy_stg.sh)
   Or from deploy/ on server: ./deploy_stg.sh <tag>
   See docs/GHCR_SETUP.md and deploy/README.md

Note: deploy/ has a single docker-compose.yml (SurrealDB, Redis, backend). Frontend
runs standalone via scripts/start-front.sh or start-tauri.sh, not in this compose.

Env files (use either per run)
  config/.env.dev   — create: ./config/setup-env.sh dev
  config/.env.prod  — create: ./config/setup-env.sh prod

  Choose which env a script uses:
  • Argument: ./scripts/start-back.sh dev   or   ./scripts/ci.sh all prod
  • Variable: ENV=dev ./scripts/start-back.sh   or   ENV=prod ./scripts/start-front.sh
  Defaults: all scripts use dev unless you pass prod or set ENV=prod.
